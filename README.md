# Suzhou SHS Intraco Ltd

Corporate website for Suzhou SHS Intraco Ltd, presenting its software solutions and technology equipment trading capabilities.

## Run locally

Open `index.html` directly, or serve the directory with any static file server.

```powershell
npx serve . -l 4173
```

## Structure

- `index.html` — semantic page content
- `styles.css` — responsive visual system
- `script.js` — navigation and reveal interactions
- `favicon.svg` — site icon

No build step or runtime dependency is required for deployment.
